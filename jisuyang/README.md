# 가수 지수양 — 개인 홍보 홈페이지

트로트 가수 **지수양**의 1페이지 인터랙티브 홍보 사이트입니다.
빌드 도구·의존성 없이 그냥 열면 동작하는 정적 사이트입니다.

**공개 주소 → https://큰길이벤트.com/jisuyang/**

```
jisuyang/
├─ index.html          # 페이지 구조
├─ css/style.css       # 디자인 (다크 스테이지 × 골드 포일)
├─ js/data.js          # ★ 내용·연락처 데이터 (여기만 고치면 됩니다)
├─ js/app.js           # 인터랙션
└─ assets/
   ├─ hero.jpg         # 히어로 배경 (녹동 바다 불꽃축제 무대)
   ├─ profile.jpg      # 프로필 사진 (유튜브 공식 채널 프로필 원본)
   └─ hero-portrait.jpg# profile.jpg 가 없을 때 쓰는 대체본
```

## 연락처

`js/data.js` 맨 위 `CONFIG` 에 들어 있습니다. 바뀌면 여기만 고치세요.

```js
phone: '010-4177-0545',
```

## 프로필 사진 교체

`assets/profile.jpg` 를 다른 사진으로 덮어쓰면 됩니다. **세로 4:5 비율** 권장.
파일을 지우면 무대 사진에서 잘라낸 대체본이 자동으로 표시됩니다.

## 열어보기

`index.html` 을 더블클릭하면 바로 열립니다.

## 배포

`keungil-event` 저장소의 `main` 브랜치에 push 하면 GitHub Pages가 자동 반영합니다 (1~2분).

## 구성 섹션

| 섹션 | 내용 |
|---|---|
| 히어로 | 무대 사진 패럴랙스 + 캔버스 불꽃/금가루, 클릭 시 폭죽 |
| 01 프로필 | 여자 어부 13년 → 투병 → 무대 복귀 스토리 |
| 02 음반 | 대표곡 4장 카드(커서 스포트라이트) + 정규 1집 31곡 검색·랜덤 선곡 |
| 03 무대영상 | 대표 6편 · 카테고리 필터 · 라이트박스 재생 |
| 04 활동/수상 | 연도별 타임라인 + 수상 경력 + 방송 채널 |
| 05 섭외문의 | 전화 연결 · 번호 복사 · 유튜브 채널 |

## 내용 수정 방법

전부 `js/data.js` 안에 있습니다.

- `TITLES` — 대표곡 카드
- `TRACKS` / `HOT_TRACKS` — 정규 1집 수록곡
- `VIDEOS` — 무대 영상 (유튜브 영상 ID만 넣으면 썸네일 자동)
- `CAREER` — 연도별 활동 경력
- `AWARDS` — 수상 경력
- `MEDIA` — 방송 출연 채널

새 무대 영상 추가 예시:

```js
{ id: '유튜브영상ID', song: '곡명', event: '행사명', date: '2026.08.15', cat: '축제' },
```
