# 큰길이벤트기획 전자명함 서버 설치 (Google Apps Script)

`card/index.html` 의 **「명함 발행하기」** 가 사용하는 백엔드입니다.
받은 명함을 저장소 **main 브랜치**에 파일로 써 넣으면, 깃허브 페이지가 1~2분 안에 올려줍니다.

```
card/{주소}/index.html   완성된 명함 (og 태그가 박혀 카톡 미리보기가 뜬다)
card/img/{주소}.jpg      명함 안에 보이는 사진
card/og/{주소}.jpg       카톡·문자 미리보기용 1200×630
```

설치는 **한 번만** 하면 됩니다.

> **갤러리 스크립트를 이미 설치하셨다면 절반은 끝났습니다.**
> `GITHUB_TOKEN` 과 `GITHUB_REPO` 는 **그때 쓴 값을 그대로** 넣으시면 됩니다.
> 토큰을 새로 만들 필요가 없습니다.
>
> 다만 **스크립트는 새로 만들어야 합니다.** 갤러리는 `photos` 브랜치에,
> 명함은 `main` 브랜치에 씁니다. 한 스크립트에 섞으면 갤러리가 망가집니다.

---

## 0) 갤러리 토큰을 그대로 쓰는 경우 (권장)

갤러리 스크립트 편집기를 열고 **⚙ 프로젝트 설정 → 스크립트 속성** 에서
`GITHUB_TOKEN` 값을 복사해 두세요. 그러면 **1단계를 건너뛰고 2단계로** 갑니다.

값이 안 보이면(가려져 있으면) 새로 만드시면 됩니다 — 1단계로.

---

## 1) GitHub 토큰 만들기 (3분) — 갤러리 토큰이 있으면 건너뜁니다

1. https://github.com/settings/personal-access-tokens/new 열기
2. 입력
   - **Token name**: `큰길 명함 발행`
   - **Expiration**: `No expiration` (또는 1년 — 만료되면 다시 만들어야 합니다)
   - **Repository access**: `Only select repositories` → **`brizymedia/keungil-event`** 선택
3. **Permissions → Repository permissions** 에서 **`Contents`** 를 **`Read and write`** 로
   (다른 항목은 건드리지 마세요)
4. **Generate token** → 나오는 `github_pat_…` 를 복사
   **이 화면을 벗어나면 다시 볼 수 없습니다.**

> 토큰은 저장소 비밀번호와 같습니다. 카톡·메일로 보내지 마시고,
> 이 문서나 코드 파일에도 적지 마세요. 아래 「스크립트 속성」에만 넣습니다.

## 2) 스크립트 만들기 (5분)

1. https://script.google.com → **새 프로젝트**
2. 기본으로 열린 `Code.gs` 내용을 **모두 지우고**, 이 폴더의 **`Code.gs`** 를 붙여넣기
   - 폰에서 하실 때는 이 주소가 편합니다 → https://github.com/brizymedia/keungil-event/blob/main/apps-script/card/Code.gs
     (오른쪽 위 **복사 단추**를 누르면 전체가 복사됩니다)
3. 프로젝트 이름을 **`큰길 명함 발행`** 으로 저장
4. 왼쪽 **⚙ 프로젝트 설정** → 맨 아래 **스크립트 속성** → **스크립트 속성 추가** 로 세 개

   | 속성 | 값 |
   |---|---|
   | `UPLOAD_PW` | 명함을 발행할 때 칠 비밀번호 (직접 정하세요) |
   | `GITHUB_TOKEN` | `github_pat_…` (갤러리와 같은 값이어도 됩니다) |
   | `GITHUB_REPO` | `brizymedia/keungil-event` |

5. **저장**

## 3) 권한 승인

1. 편집기 위쪽 함수 목록에서 **`권한받기`** 를 고르고 **실행**
2. 권한 요청 창 → 계정 선택 → **고급 → 안전하지 않은 페이지로 이동** → **허용**
   (바깥 인터넷에 연결하는 권한 하나만 씁니다. 드라이브·메일 권한은 요청하지 않습니다)
3. 함수 목록에서 **`점검`** 을 골라 **실행** → 아래 **실행 로그**가 이렇게 나오면 정상입니다

   ```
   UPLOAD_PW: 있음
   GITHUB_TOKEN: 있음
   GITHUB_REPO: 있음
   깃허브 연결 정상 — card 폴더에 3개 있습니다
   ```

   처음이면 「card 폴더는 아직 비어 있습니다」로 나옵니다. **그래도 정상입니다.**
   「없음」이나 「거절했습니다」가 있으면 2단계를 다시 보세요.

## 4) 웹앱으로 배포

1. 우측 상단 **배포 → 새 배포**
2. 톱니바퀴 → 유형 **웹 앱**
3. 설정
   - 설명: `card v1`
   - **다음 사용자로 실행: 나**
   - **액세스 권한: 모든 사용자** ← 폰에서 열어야 하므로 반드시 이것
4. **배포**
5. 나오는 **웹 앱 URL** 복사 — `https://script.google.com/macros/s/AKfycb…/exec`

> 「모든 사용자」여도 아무나 명함을 올릴 수는 없습니다.
> `UPLOAD_PW` 가 맞아야 통과합니다.

## 5) 명함 만들기 화면에 연결

1. https://큰길이벤트.com/card 열기
2. 맨 아래 **발행** 칸의 **「명함 서버 주소」** 에 4단계 주소를 붙여넣기
3. 이 브라우저에만 저장되고 다시 묻지 않습니다. 기기를 바꾸면 한 번 더 넣습니다

주소를 잃어버렸으면 스크립트 편집기 **배포 → 배포 관리** 에서 다시 볼 수 있습니다.

## 6) 시험해 보기

1. 이름·휴대폰만 넣고 **주소 정하기** 에 `test` 라고 적습니다
2. 비밀번호를 넣고 **명함 발행하기**
3. 「명함을 발행했습니다」가 뜨면 성공입니다
4. **1~2분 뒤** `https://큰길이벤트.com/card/test` 를 열어보세요
5. 카톡으로 그 주소를 자기 자신에게 보내 **미리보기 그림이 뜨는지** 확인

시험용 명함은 나중에 지우시면 됩니다 (아래 참고).

---

## 코드를 고친 뒤에는

Apps Script 는 **저장만으로는 반영되지 않습니다.**
**배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포** 를 해야 바뀝니다.
이때 주소는 그대로라 5단계를 다시 할 필요는 없습니다.

## 명함 지우기

발행한 명함을 내리려면 스크립트 편집기에서 이렇게 한 줄 실행하시면 됩니다.

```js
function 명함지우기() {
  Logger.log(명함삭제({ slug: 'test' }));
}
```

`test` 자리에 지울 명함 주소를 넣으세요. `card/test/index.html` 과 사진 두 장이 함께 지워집니다.

## 잘 안 될 때

| 증상 | 볼 곳 |
|---|---|
| 「비밀번호가 다릅니다」 | `UPLOAD_PW` 와 화면에 친 비밀번호가 같은지 |
| 「깃허브 저장 실패 (401)」 | 토큰이 틀렸거나 만료됨 → 1단계 다시 |
| 「깃허브 저장 실패 (403)」 | 토큰에 `Contents: Read and write` 가 없음 |
| 「깃허브 저장 실패 (404)」 | `GITHUB_REPO` 오타 — `brizymedia/keungil-event` |
| 발행은 됐는데 주소가 안 열림 | 깃허브 페이지 배포 중. 1~2분 기다렸다 새로고침 |
| 카톡 미리보기가 안 뜸 | 카톡이 한 번 본 주소는 기억합니다. 주소 뒤에 `?1` 을 붙여 보내보세요 |
| 「다른 발행이 진행 중」 | 20초 뒤 다시 |

**저장소 → Actions** 에서 초록불이 켜졌는지도 보실 수 있습니다.
