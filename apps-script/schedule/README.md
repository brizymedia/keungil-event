# 큰길이벤트기획 행사 일정 대장 서버 설치 (Google Apps Script)

`schedule.html`(행사 일정 대장)이 쓰는 무료 백엔드입니다. 설치하면 다음이 됩니다.

- 행사 개요 · 행사 일정표 · 필요 품목표를 **팀 전원이 같은 주소에서** 보고 고침 (구글 시트에 저장)
- 전자계약(`contract.html`)에서 **서명이 끝난 행사는 자동으로 「확정」** 표시 + 계약서 PDF 링크
- 서명은 됐는데 일정에 없는 행사는 **「일정에 추가」 한 번**으로 계약 품목까지 끌어옴

서버 없이도 `schedule.html`은 동작하지만 **그 기기(브라우저)에만 저장**됩니다. 팀 공유용으로는 서버 설치가 필요합니다.

---

## 1) 스크립트 만들기 (5분)

전자계약 서버(`apps-script/contract`)를 이미 깔았다면 **같은 구글 계정**으로 하세요. 그래야 `계약 대장`을 읽어 확정 표시가 됩니다.

1. https://script.google.com → **새 프로젝트**
2. 기본으로 열린 `Code.gs` 내용을 모두 지우고, 이 폴더의 **`Code.gs`** 내용을 붙여넣기
3. 프로젝트 이름: `큰길 행사 일정` 등으로 저장

## 2) 웹앱으로 배포

1. 우측 상단 **배포 → 새 배포**
2. 톱니바퀴 → 유형 **웹 앱**
3. 설정
   - 설명: `schedule v1`
   - **다음 사용자로 실행: 나**
   - **액세스 권한: 모든 사용자**  ← 직원 폰·다른 컴퓨터에서 열어야 하므로 반드시 "모든 사용자"
4. **배포** → 권한 승인 → "고급 → 안전하지 않은 페이지로 이동" → 허용 (드라이브 · 스프레드시트 권한)
5. 표시되는 **웹 앱 URL** 복사 `https://script.google.com/macros/s/AKfycb…/exec`

## 3) schedule.html 에 연결

방법 A (권장) — 파일에 고정
`schedule.html` 상단 `const 서버주소_기본 = '';` 에 URL 을 넣어 배포하면 누가 열어도 바로 같은 대장이 보입니다.

방법 B — 화면에서 한 번 입력
1. `https://큰길이벤트기획.com/schedule.html` 열기 → 상단 **「서버」** 버튼
2. 웹 앱 URL 붙여넣기 → 저장
3. **「공유 링크 복사」** 로 만든 링크(`schedule.html?s=…`)를 팀에 보내면 받는 쪽은 설정이 필요 없습니다

## 4) 사용 흐름

1. **행사 등록** — 「새 행사」→ 행사명 · 일시 · 장소 · 참석 · 주최 · 주요내용 입력 → 상태는 `문의 / 견적 / 확정 / 완료 / 취소`
2. **행사 일정표** — 구분(식전·개회·포럼…) · 시간 · 소요 · 주요내용 · 비고 행을 추가
3. **필요 품목** — 견적서 품목을 그대로 옮기고 수량 · 담당 · 준비완료 체크
4. **확정** — 전자계약 서명이 끝나면 다음 새로고침 때 자동으로 「확정」 (계약번호 또는 행사명+행사일로 맞춤). 계약 없이 확정된 행사는 상태를 직접 「확정」으로 바꿔도 됩니다
5. **인쇄** — 행사를 고른 뒤 「인쇄」→ A4 한 장짜리 행사 추진계획 (개요 · 일정 · 품목)

## 데이터 위치

- 드라이브 `큰길이벤트기획 계약서/행사 일정 대장` (스프레드시트, 시트 `행사`)
  - 한 행 = 행사 하나. 마지막 `JSON` 열이 원본이므로 시트에서 직접 고치려면 `JSON` 열을 건드리지 말고 화면에서 고치세요
- 계약 확정 판단은 같은 폴더의 `계약 대장` 에서 상태가 `서명완료` 인 행을 읽습니다

## 코드를 고친 뒤 재배포

**배포 → 배포 관리 → (연필) → 버전: 새 버전 → 배포** (URL 유지)

## 문제 해결

| 증상 | 확인 |
|---|---|
| 「서버 응답을 읽을 수 없습니다」 | 배포 액세스 권한이 "모든 사용자"인지. 새 버전으로 재배포 |
| 서명이 끝났는데 「확정」이 안 됨 | 전자계약 서버와 **같은 구글 계정**인지. 행사명 · 행사일이 계약서와 같은지, 아니면 행사 편집에서 계약번호를 넣기 |
| 두 사람이 동시에 고쳤더니 하나가 사라짐 | 마지막 저장이 이깁니다. 저장 전 「새로고침」으로 최신 내용을 받은 뒤 고치세요 |
