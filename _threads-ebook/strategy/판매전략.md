# 스레드 자동화 전자책 — 조사 결과와 판매 전략

작성: 2026-09-26 · 경쟁 강의 분석을 반영해 개정

## 1. 참고한 강의의 내용

참고 링크(네이버 카페 「바이브스쿨」 9275번 글)는 카페 회원만 볼 수 있어서 본문을 직접 읽지 못했습니다.
그래서 처음에는 이 카페의 게시판 구성과 같은 주제의 공개 강의·상품을 조사했습니다. 이후 대표님이 보내 주신 모집 글 사본(350,000원 VOD 강의)으로 경쟁 분석을 따로 했습니다 → `경쟁분석-올인원강의.md`

### 요즘 "스레드 자동화" 강의가 가르치는 5가지

| # | 방식 | 내용 | 평가 |
|---|---|---|---|
| ① | **AI 원고 대량 생성** | ChatGPT·Claude 프롬프트로 한 번에 30일 치 글 생성 | ◎ 핵심. 전자책 2부에 넣음 |
| ② | **공식 Threads API 예약 발행** | 개발자 앱 → 토큰 → 컨테이너 만들기·발행 2단계 | ◎ 안전. 전자책 3부와 `tool/`에 구현 |
| ③ | **노코드 자동화** (n8n·Make) | 스케줄 → AI → HTTP 요청으로 발행 | ○ 코딩 없는 대안. 전자책 3-6에 소개 |
| ④ | **댓글 키워드 → 링크·DM 퍼널** | "댓글에 '자료' 남기면 드려요" → 무료 PDF → 유료 상품 | ◎ 수익화의 핵심. 전자책 4부와 `tool`의 `replies`에 구현 |
| ⑤ | **비공식 자동화 프로그램** | 아이디·비밀번호 입력, 자동 좋아요·댓글·리포스트·팔로우 | ✕ 약관 위반·계정 정지 위험. **책에서 "쓰지 말라"고 명시** |

### 공식 API에서 확인한 사실 (Meta 개발자 문서, 2026년 기준)

- 사용료 없음. 24시간 동안 계정 하나당 게시물 250개, 답글 1,000개, 삭제 100개까지 올릴 수 있음
- 발행은 2단계: `POST /{user-id}/threads`로 컨테이너 생성 → `POST /{user-id}/threads_publish`로 발행
- 예약 발행 기능이 따로 없어서 스케줄러(cron·GitHub Actions)를 직접 만들어야 함. 컨테이너는 24시간 뒤 만료됨
- 토큰: 짧은 토큰은 1시간, 장기 토큰은 60일. `refresh_access_token`으로 연장
- 내 계정만 쓸 때는 앱 검수 없이 개발 모드에 테스터로 등록하면 됨
- 키워드 검색(`threads_keyword_search`), 답글 관리, 인사이트 API가 있음

- 경쟁 상품 대부분이 "월 1천만 원" 같은 **수익 숫자**로 팝니다. 우리는 **안전함, 실제 운영 사례, 바로 쓰는 도구**로 차별화합니다.

## 2. 우리의 포지셔닝 (2026-09-26 경쟁 분석 반영)

> 경쟁 분석 전문: `경쟁분석-올인원강의.md`

350,000원짜리 스레드 자동화 VOD 강의가 몇 분 만에 마감되고 있습니다. **수요는 확인됐습니다.** 그 강의가 팔리는 힘은 **증거**(월 조회수 수백만, 매출 캡처, 카페 2만 명)입니다. 지금 우리에게는 스레드 증거가 없습니다. 그래서 전략을 이렇게 바꿉니다.

### 두 갈래로 간다

| | A. 입문자 (개인·부업) | B. 사장님 (지역 업체·행사업체) ⭐ |
|---|---|---|
| 시장 | 경쟁이 가장 치열함 (AI 부업) | **거의 비어 있음** |
| 우리의 무기 | 도구 제공 + 공식 API라 안전함 + 합리적 가격 | 큰길이벤트의 고객망, 행사 현장 콘텐츠, "우리도 이렇게 운영한다"는 사례 |
| 상품 | 전자책 → 셀프 키트 → 소그룹 기수 | 세팅 대행 + 월 운영 관리 |
| 역할 | 후기·증거·리드 쌓기 | **실제 매출의 중심** |

### 한 줄 약속

- A: **"방법만이 아니라, 돌아가는 도구까지 드립니다. 공식 API라 계정 걱정 없이."**
- B: **"사장님은 장사만 하세요. 가게 스레드는 매일 알아서 올라갑니다."**

### 차별점

1. **도구 제공**: 경쟁 강의에는 "프로그램도 주나요?"라는 질문이 남아 있습니다. 우리는 실행되는 `threads-autopost`를 드립니다.
2. **구조적 안전**: 공식 API만 쓰고, 남의 게시물에 자동 댓글을 달거나 여러 계정을 자동으로 돌리지 않습니다. 단, "100% 안전"이라고 약속하지는 않습니다.
3. **잘 된 글 분석**: 경쟁 강의 수강생이 가장 좋다고 한 부분(잘 된 글 분석 → AI가 내 분야로 변형)을 도구의 `analyze` 명령으로 자동화했습니다.
4. **진짜 사례, 진짜 숫자**: 블로그 자동 발행 실적 + 앞으로 6~8주 동안 쌓을 스레드 기록. 수익 배수나 월 매출 약속은 쓰지 않습니다.

## 3. 상품 구성 (가격 사다리, 경쟁 가격 반영)

경쟁 강의는 290,000 → 350,000 → 490,000원으로 오릅니다. **49,000~190,000원 구간이 비어 있어** 여기를 채웁니다.

| 단계 | 상품 | 가격 | 들어가는 것 | 여는 시점 |
|---|---|---|---|---|
| 0 | 무료 자료 | 0원 | 30일 체크리스트 + 첫 줄 공식 12가지 | 2주 차 |
| 1 | 입문 전자책 | 19,900원 | 전자책 PDF | 4주 차 |
| 2 | **셀프 키트** ⭐ | **79,000원** | 전자책 + 도구 + 설치 영상 + 프롬프트 + 원고 90개 예시 + `analyze` 사용법 | 4주 차 |
| 3 | **소그룹 기수** (4주) | 1기 149,000원 → 2기 190,000원 → 3기 250,000원 | 셀프 키트 + 주 1회 줌 Q&A(총 4회) + 1:1 계정 점검 1회 + 단톡방 | 8주 차 (증거가 쌓인 뒤) |
| 4 | 세팅 대행 | 300,000원 | 앱·토큰·자동 실행을 원격으로 대신 세팅 + 30일 원고 | 소그룹 1기 이후 |
| B | **사장님 스레드 운영** | 세팅 300,000원 + 월 150,000원 | 가게 계정 세팅, 월 90개 원고 작성·검수·발행, 월간 리포트 | 1주 차부터 (기존 고객에게 먼저 제안) |

가격 원칙:
- **기수 인원 한정은 진짜 이유가 있을 때만**: 줌 Q&A와 1:1 점검을 감당할 수 있는 인원(예: 20명)으로 정합니다.
- **가격 계단은 공지한 대로 지킵니다.** 다음 기수 가격을 미리 알리고 실제로 올립니다.
- **후기 보상**: 구매자 전원에게 개정판 무료. 후기를 쓰면 월 1회 라이브 Q&A에 초대합니다. 후기를 쓰는 조건으로 할인하지는 않습니다(추천·보증 심사지침상 대가를 표시해야 함).

## 5. 출시 계획 — 증거 먼저, 판매는 그다음

### 0단계: 증거 만들기 (1~6주)

경쟁 상품을 이기는 것은 카피가 아니라 증거입니다. 판매보다 기록을 먼저 합니다.

| 주차 | 스레드 (계정 2개: 회사 계정 + "자동화 기록" 개인 계정) | 인스타 | 상품·판매 |
|---|---|---|---|
| **1주** | 두 계정 모두 하루 3개 자동 발행 시작. 프로필에 무료 자료 링크 | 프로필 정리 | 크몽 판매자 등록. **B(사장님) 상품을 기존 고객 5곳에 먼저 제안** |
| **2주** | "자동화 만드는 과정" 연재 (실제 화면 캡처) | 카드뉴스 주 3회, ManyChat 설정 | 무료 체크리스트 공개, 대기자 명단 오픈 |
| **3주** | 첫 `analyze` 실행 → 잘 된 글 패턴 공개 | 릴스: 자동 발행 화면 녹화 | **베타 10명 모집** (셀프 키트 무료 제공, 솔직한 후기 요청) |
| **4주** | 베타 참여자 질문을 글감으로 활용 | 베타 후기 카드뉴스 (동의받은 것만) | 입문 전자책 19,900원 + 셀프 키트 79,000원 오픈 (크몽) |
| **5~6주** | 30일 회고: 실제 숫자 공개 (조회수, 답글률, 발행 누락 0건) | 회고 카드뉴스 | B 상품 첫 사례 정리 (고객 동의받고) |

## 6. 법·세무 체크 (판매 전 필수)

- **과장 광고 금지**: "누구나 월 ○○만 원" 같은 수익 보장 표현, 가짜 후기, 조작된 수익 인증은 「표시·광고의 공정화에 관한 법률」 위반이 될 수 있습니다.
- **추천·보증 표기**: 제휴 링크나 협찬에는 "광고", "제휴 수수료를 받을 수 있음"을 적습니다 (공정위 추천·보증 심사지침).
- **개인정보**: 신청 폼에 수집 항목, 목적, 보유 기간을 쓰고 동의를 받습니다. 광고성 메일·메시지는 수신 동의를 따로 받습니다.
- **사업자등록·통신판매업**: 크몽 같은 플랫폼에서 소액으로 시작하는 건 개인으로도 가능한 경우가 많습니다. 하지만 반복해서 팔거나 자체 결제로 팔면 사업자등록과 통신판매업 신고가 필요합니다. 큰길이벤트 사업자로 판매한다면 **업종 추가**(전자책·교육 서비스)를 세무사와 상의하세요.
- **부가세**: 전자출판물은 요건에 따라 면세·과세가 달라지므로 세무사나 국세청(126)에 확인합니다.
- **저작권**: 전자책 표지·본문 이미지는 상업용 라이선스가 있는 것만 씁니다. PDF에 "무단 배포 금지" 문구와 구매자 정보 워터마크를 넣으면 유출을 줄일 수 있습니다.
