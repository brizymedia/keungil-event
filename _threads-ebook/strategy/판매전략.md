# 스레드 자동화 전자책 — 조사 결과와 판매 전략

작성: 2026-09-26

## 1. 참고한 강의의 내용

참고 링크(네이버 카페 「바이브스쿨」 9275번 글)는 카페 회원만 볼 수 있어서 본문을 직접 읽지 못했습니다.
그래서 이 카페의 게시판 구성(스레드/페이스북, AI 부업, 무료·유료 전자책, 자동화)과 같은 주제의 공개 강의·상품을 조사해 정리했습니다.

### 요즘 "스레드 자동화" 강의가 가르치는 5가지

| # | 방식 | 내용 | 평가 |
|---|---|---|---|
| ① | **AI 원고 대량 생성** | ChatGPT·Claude 프롬프트로 한 번에 30일 치 글 생성 | ◎ 핵심. 전자책 2부에 넣음 |
| ② | **공식 Threads API 예약 발행** | 개발자 앱 → 토큰 → 컨테이너 만들기·발행 2단계 | ◎ 안전. 전자책 3부와 `tool/`에 구현 |
| ③ | **노코드 자동화** (n8n·Make) | 스케줄 → AI → HTTP 요청으로 발행 | ○ 코딩 없는 대안. 전자책 3-6에 소개 |
| ④ | **댓글 키워드 → 링크·DM 퍼널** | "댓글에 '자료' 남기면 드려요" → 무료 PDF → 유료 상품 | ◎ 수익화의 핵심. 전자책 4부와 `tool`의 `replies`에 구현 |
| ⑤ | **비공식 자동화 프로그램** | 아이디·비밀번호 입력, 자동 좋아요·댓글·리포스트·팔로우 | ✕ 약관 위반·계정 정지 위험. **책에서 "쓰지 말라"고 명시** |

### 공식 API에서 확인한 사실 (Meta 개발자 문서, 2026년 기준)

- 사용료 없음. 24시간 동안 계정 하나당 게시물 250개, 답글 1,000개, 삭제 100개까지 올릴 수 있음
- 발행은 2단계: `POST /{user-id}/threads`로 컨테이너 생성 → `POST /{user-id}/threads_publish`로 발행
- 예약 발행 기능이 따로 없어서 스케줄러(cron·GitHub Actions)를 직접 만들어야 함. 컨테이너는 24시간 뒤 만료됨
- 토큰: 짧은 토큰은 1시간, 장기 토큰은 60일. `refresh_access_token`으로 연장
- 내 계정만 쓸 때는 앱 검수 없이 개발 모드에 테스터로 등록하면 됨
- 키워드 검색(`threads_keyword_search`), 답글 관리, 인사이트 API가 있음

### 시장 조사 (크몽 「부업·수익화 전자책」 카테고리, 2026년 9월)

| 상품 | 가격 | 후기 수 | 시사점 |
|---|---|---|---|
| AI+스레드로 월1천만원 달성 수익화 자동화 패키지 | 159,000원~ | 373 | 스레드 자동화 수요가 확실함. 고가도 팔림 |
| SNS 3채널 자동발행 스타터킷 | 29,000원 | 신규 | 자동 발행 도구 번들은 저가 진입 상품 |
| AI+인스타그램 수익화 마스터 패키지 | 299,000원~ | 16 | 인스타 확장 상품의 가격 기준 |
| 전자책 기획부터 판매까지 올인원 | 59,000원 | 신규 | "전자책 만드는 법" 자체도 상품이 됨 |

- 크몽 전자책 카테고리의 수수료는 약 20% 내외이고 등록 심사가 있습니다. 조건은 바뀔 수 있으니 등록 전에 확인해야 합니다.
- 경쟁 상품 대부분이 "월 1천만 원" 같은 **수익 숫자**로 팝니다. 우리는 **안전함, 실제 운영 사례, 바로 쓰는 도구**로 차별화합니다.

## 2. 우리의 포지셔닝

> **"계정 안 날리는 스레드 자동화 — 공식 API로 매일 자동 발행, 답글이 매출로 이어지는 구조까지"**

차별점 3가지:

1. **안전**: 공식 API만 씁니다. 로그인 매크로를 쓰지 않습니다. 경쟁 상품의 "무료 자동화 프로그램"에 불안해하는 사람을 공략합니다.
2. **진짜 사례**: 큰길이벤트는 이미 블로그·갤러리·칼럼을 AI와 GitHub Actions로 자동 발행하고 있습니다. 이 과정을 캡처와 기록으로 보여 주면 **"실제로 돌아가는 시스템"**이라는 증거가 됩니다. 숫자는 실제 값만 씁니다.
3. **도구 포함**: 책만 파는 게 아니라, 바로 실행되는 도구(`threads-autopost`), 프롬프트, 30일 캘린더를 함께 줍니다.

## 3. 상품 구성 (가격 사다리)

| 단계 | 상품 | 가격 | 들어가는 것 |
|---|---|---|---|
| 0 | **무료 자료** | 0원 | 「스레드 첫 30일 체크리스트」 1장 + 훅 공식 12가지 (`marketing/무료자료-체크리스트.md`) |
| 1 | **입문 전자책** | 19,900원 (얼리버드 9,900원, 선착순 50명) | 이 책 PDF |
| 2 | **자동화 번들** ⭐ 주력 | 49,000원 | 전자책 + 자동 발행 도구 + 설치 영상 + 프롬프트 모음 + 30일 원고 90개 예시 |
| 3 | **세팅 대행** | 150,000원 | 앱 만들기·토큰·GitHub Actions 세팅을 원격으로 대신 해 줌 + 30일 원고 1회 |
| 4 | **(선택) 소상공인·행사업체용** | 문의 | 본업(행사 대행) 고객에게 SNS 자동화를 부가 서비스로 판매 |

- 처음에는 **1단계와 2단계만** 엽니다. 후기가 20개 넘게 쌓이면 가격을 올리고 3단계를 엽니다.
- 얼리버드 인원 같은 "한정"은 실제로 지킬 수 있는 조건만 겁니다.

## 4. 판매 채널

| 채널 | 역할 | 시작 시점 |
|---|---|---|
| **스레드** | 매일 3~5개 자동 발행. 주 2회는 "댓글에 '자료' → 무료 체크리스트" 글 | 1주 차 |
| **인스타그램** | 스레드에서 잘 된 글을 카드뉴스로 바꿔 주 3회 발행. ManyChat으로 댓글 키워드 → DM | 2주 차 |
| **크몽** | 결제·PDF 전달·검색 유입. 입문 전자책과 번들 등록 | 3주 차 (심사 기간 고려해 1주 차에 신청) |
| **자체 판매 링크** | 스레드·인스타 프로필 링크 → 결제 → 자동 메일 (수수료 절감) | 월 판매가 꾸준해진 뒤 (통신판매업 신고 필요) |
| **네이버 블로그·카페** | 기존 블로그 자동화 루틴에 「SNS 자동화」 칼럼 추가 → 검색 유입 | 2주 차 |

### 퍼널

```text
스레드·인스타 글 (매일 자동 발행)
  → "댓글에 '자료' 남기면 드려요" (주 2회)
  → 자동 답글·DM으로 무료 체크리스트 링크 (tool: npm run replies / ManyChat)
  → 신청 폼 (이메일 + 개인정보·광고 수신 동의)
  → 3일 뒤 안내 메일: 입문 전자책 얼리버드
  → 7일 뒤: 자동화 번들 (도구 포함)
  → 구매자 대상: 세팅 대행
```

## 6. 법·세무 체크 (판매 전 필수)

- **과장 광고 금지**: "누구나 월 ○○만 원" 같은 수익 보장 표현, 가짜 후기, 조작된 수익 인증은 「표시·광고의 공정화에 관한 법률」 위반이 될 수 있습니다.
- **추천·보증 표기**: 제휴 링크나 협찬에는 "광고", "제휴 수수료를 받을 수 있음"을 적습니다 (공정위 추천·보증 심사지침).
- **개인정보**: 신청 폼에 수집 항목, 목적, 보유 기간을 쓰고 동의를 받습니다. 광고성 메일·메시지는 수신 동의를 따로 받습니다.
- **사업자등록·통신판매업**: 크몽 같은 플랫폼에서 소액으로 시작하는 건 개인으로도 가능한 경우가 많습니다. 하지만 반복해서 팔거나 자체 결제로 팔면 사업자등록과 통신판매업 신고가 필요합니다. 큰길이벤트 사업자로 판매한다면 **업종 추가**(전자책·교육 서비스)를 세무사와 상의하세요.
- **부가세**: 전자출판물은 요건에 따라 면세·과세가 달라지므로 세무사나 국세청(126)에 확인합니다.
- **저작권**: 전자책 표지·본문 이미지는 상업용 라이선스가 있는 것만 씁니다. PDF에 "무단 배포 금지" 문구와 구매자 정보 워터마크를 넣으면 유출을 줄일 수 있습니다.
