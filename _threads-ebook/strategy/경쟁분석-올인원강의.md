# 경쟁 분석 — 350,000원짜리 "스레드 AI 자동화 올인원" VOD 강의

작성: 2026-09-26 · 자료: 네이버 카페에 올라온 유료 VOD 강의 모집 글(2026-08-29). 이미지 32장을 글자로 바꾼 사본을 대표님이 보내 주셨습니다.
원문은 공개 저장소에 올리지 않았고, 이 문서에는 분석 내용만 적었습니다.

## 1. 한눈에 보기

| 항목 | 경쟁 강의 | 우리 (현재 계획) |
|---|---|---|
| 형태 | VOD 강의, 매달 기수를 모집해 선착순 마감 | 전자책 + 실행되는 도구 |
| 가격 | 290,000원 → **350,000원** → 490,000원 (기수마다 인상) | 19,900원 / 49,000원 / 150,000원 |
| 핵심 약속 | "하루 5분", 한 달 치 30개를 한 번에 예약 | "잠든 사이에도 글이 올라간다" |
| 커리큘럼 | 3장: 글쓰기 자동화 · 댓글 자동화 · 예약 발행 자동화 (+ 여러 계정 운영) | 6부: 원고 → 공식 API 발행 → 판매 퍼널 → 운영 |
| 증거 | 직접 운영하는 계정 3개, 월 조회수 304만·106만·23만, "연결매출" 5,698만 원, 쿠팡파트너스 240만 원, 카페 회원 2만 명, 수강생 수익 인증 | **아직 없음** (블로그 자동 발행 실적만 있음) |
| 계정 안전 | "100% 보장 못 함, 계정별 운영 기준이 중요" | 공식 API만 사용 (로그인 매크로 없음) |
| 프로그램 제공 | 불명확. 댓글에 "프로그램도 주나요, 방법만 알려 주나요?"라는 질문이 있음 | **도구 제공** (`threads-autopost`) |
| 판매 성과 | 8월 모집 9분 만에 마감, 9월 12분 만에 마감 | — |

**결론:** 350,000원에도 몇 분 만에 마감될 만큼 **수요는 확실합니다.** 경쟁 강의가 팔리는 힘은 **증거**(조회수, 매출, 커뮤니티)에서 나오고, 우리에게는 지금 그게 없습니다. 그래서 정면으로 붙기 전에 **증거를 쌓는 단계**가 필요합니다. 차별점은 **도구 제공**, **공식 API라 안전함**, **사장님 시장**입니다.

## 2. 상세페이지 흐름 (12단계)

| # | 단계 | 쓰는 장치 | 우리가 따라 할 것 / 피할 것 |
|---|---|---|---|
| 1 | 오프닝 | "9분 만에 마감" + 놓쳐서 아쉬워하는 카톡·댓글 캡처 | ○ **실제로 마감됐을 때만**. 첫 기수는 "베타 10명"처럼 작게 열어 진짜 마감 기록을 만든다 |
| 2 | 훅 + 자격 | "진짜로 AI로 자동화해서 운영하는 사람" | ○ "행사 회사가 블로그·갤러리를 몇 달째 자동 발행 중" (실제 사실) |
| 3 | 초반 후기 + 가격 인상 예고 | 290,000 → 350,000 → 490,000 | ○ 기수제 가격 계단. 단, 올리겠다고 한 가격은 **반드시 지킨다** |
| 4 | 문제 → 전후 비교 | "매일 30번 반복 → 한 달에 한 번" | ◎ 그대로 쓴다. 전자책 2부와 같은 메시지 |
| 5 | 증거 | 계정 3개, 조회수, 매출 캡처 | △ 우리는 6~8주 동안 만든 **실제 숫자**만 쓴다 |
| 6 | 수강생 수익 인증 | 33만 원, 29만 원, "강의비 1000배" | ✕ "1000배" 같은 수익 강조는 쓰지 않는다. 대신 "발행 누락 0건", "주 3시간 절약" 같은 **과정 성과**를 보여 준다 |
| 7 | 반론 처리 | "계정 터지지 않나요?" → 100% 보장 안 함 | ◎ 솔직하게 쓰는 방식은 좋다. 우리는 "공식 API"라는 **구조적 답**이 있어 더 강하다 |
| 8 | 강사 강의력 | 이전 챌린지 후기 3개 | ○ 베타 참여자 후기로 대신한다 |
| 9 | 결과물 | "내 계정 운영 구조 완성" + 3장 커리큘럼 | ◎ "강의가 끝나면 **내 계정에서 자동 발행이 돌아가는 상태**" |
| 10 | 가치 더하기 | 매달 업데이트, 후기 남기면 무제한 업데이트, 수익화까지 확장 | ○ 개정판 무료 + 후기 작성자는 월 1회 라이브 Q&A 초대 |
| 11 | FAQ → 가격 카드 → 행동 촉구 → 가격 인상 재강조 | | ◎ 구조를 그대로 쓴다 |
| 12 | 신청 버튼 아래 추가 후기 | | ○ |

## 3. 수강생이 실제로 좋다고 한 것 (후기에서 뽑음)

1. **"잘 터진 글을 분석한 뒤 AI에게 맡기니 품질이 높고, 내 분야에 옮겨도 어색하지 않다"** → 가장 자주 나온 칭찬입니다. 우리 도구에 `analyze` 명령을 추가했습니다.
2. **"방법을 통째로 알려 줘서 응용할 수 있다"** → 도구보다 **작업 방식**을 원합니다.
3. **"AI에게 바로 고치라고 하지 말고, 먼저 지금 구조부터 설명하게 한다"** 같은 작업 요령 → 전자책 부록에 "AI와 일하는 요령"을 넣으면 좋습니다.
4. **"자동 70% + 손으로 30%"라는 생각** → 완벽한 자동화보다 끝까지 해 보는 것이 중요하다는 메시지입니다. 전자책에 반영했습니다.
5. **"1강만 듣고 자동화를 거의 완성했다"** → 빠른 첫 성공이 만족도를 결정합니다. 우리는 "5분 시작" 흐름으로 첫날 발행 1건을 목표로 합니다.

## 4. 경쟁 강의의 빈틈 = 우리의 기회

| 빈틈 | 근거 | 우리의 대응 |
|---|---|---|
| **프로그램을 주는지 불명확** | 댓글: "자동화 프로그램도 주나요, 방법만 알려 주나요?" | 헤드라인: **"방법만이 아니라 돌아가는 도구까지 드립니다"** |
| **계정 안전을 보장 못 함** | FAQ: "100% 안전을 보장하지 않습니다" | 공식 API만 사용, 남의 글에 자동 댓글·좋아요 안 함. 구조적으로 안전하다는 점을 강조 (단, 우리도 "100% 보장"은 쓰지 않는다) |
| **결제하다 놓친 사람이 많음** | 댓글: 무통장 입금 계좌를 쓰는 사이 마감, 추가 자리를 문의하는 카톡 여러 건 | **카드 결제** + **대기자 명단**(카카오 채널·폼) + 다음 기수를 먼저 안내 |
| **가격이 비쌈** (350,000 → 490,000원) | 가격 계단 | 49,000~190,000원 구간이 비어 있음 → 합리적인 가격으로 입문자를 흡수 |
| **"AI 부업" 시장에만 머묾** | 운영 계정 3개가 모두 부업·수익화 주제 | **사장님·지역 업체** 시장은 거의 비어 있음 → 큰길이벤트의 고객망 활용 |
| **과장 위험** | 프로필 문구 "월 1억", "강의비 1000배", "하루 5분 딸깍" | 우리는 실제 숫자만 쓴다 → 오래 가는 신뢰, 광고 규제 위험 없음 |

## 5. 따라 하면 안 되는 것

- **수익 배수·월 매출 약속**("1000배", "월 천", "월 1억"): 「표시·광고의 공정화에 관한 법률」상 기만 광고가 될 수 있습니다. 후기를 인용하는 것도 광고주 책임이 될 수 있습니다.
- **"연결매출" 같은 정의가 모호한 숫자**: 무엇을 셌는지 설명하지 못하면 쓰지 않습니다.
- **가짜 희소성**: 계속 받을 수 있는데 "마감 임박"이라고 하거나, 인상하겠다고 한 가격을 지키지 않는 것.
- **여러 계정 자동화, 남의 게시물 자동 댓글**: 메타 정책상 스팸·조작 행위로 볼 수 있습니다. 우리는 **내 글에 달린 답글에만** 자동 답글을 답니다.
- **쿠팡파트너스 게시물**: 경쟁 강의가 수익원으로 쓰는 만큼 따라 하려면 "쿠팡 파트너스 활동의 일환으로 수수료를 받을 수 있음" 표기가 **필수**입니다.
