# 스레드 자동화 전자책 프로젝트

AI와 스레드 자동화로 전자책을 만들어 스레드와 인스타그램에서 파는 데 필요한 자료입니다.

| 폴더 | 내용 |
|---|---|
| `strategy/판매전략.md` | 조사 결과, 포지셔닝(입문자 · 사장님 두 갈래), 가격 사다리, 채널, 증거 먼저 출시 계획, 법·세무 체크 |
| `strategy/경쟁분석-올인원강의.md` | 350,000원 스레드 자동화 VOD 강의의 상세페이지·가격·후기 분석, 빈틈과 대응 |
| `tool/` | **공식 Threads API 자동 발행 도구**: 예약 발행, AI 원고 생성, 잘 된 글 분석(`analyze`), 키워드 자동 답글, 성과 조회 |
| `marketing/` | 스레드 출시 원고 30개(+1주 차 발행용 JSON), 인스타 카드뉴스, 크몽 상세페이지, 소그룹 기수 상세페이지(12단계), 베타 모집 글, 사장님용 제안 문구, 무료 체크리스트 |
| `ebook/` | 전자책 PDF 빌드 스크립트. 원고와 PDF는 유료 상품이라 공개 저장소에 올리지 않음 (`.gitignore`) |

전자책 PDF 다시 만들기: `ebook/`에 `ebook.md`를 넣고 `npm install && npm run build`를 실행합니다.

폴더 이름이 `_`로 시작하기 때문에 GitHub Pages(Jekyll)가 이 폴더를 사이트에 올리지 않습니다.
