# 인스타그램 카드뉴스 · 크몽 상세페이지 카피

## 1. 인스타그램 카드뉴스 3세트

카드 크기는 1080×1350(4:5)입니다. 캔바나 미리캔버스에서 같은 템플릿으로 통일해 만드세요.

### 세트 A — "매일 쓰지 마세요"

| 장 | 문구 |
|---|---|
| 1 | 스레드, 매일 쓰지 마세요 |
| 2 | 매일 쓰면 매일 고민해요. "오늘 뭐 쓰지?" |
| 3 | 일요일 30분, 한 주 치 21개를 몰아서 쓰세요 |
| 4 | AI가 초안 → 내가 경험 한 줄 추가 |
| 5 | 공식 API로 예약 → 평일엔 자동 발행 |
| 6 | 저장해 두고, 댓글에 '자료' 남기면 체크리스트 드려요 |

**캡션:** 꾸준함은 의지가 아니라 구조에서 나와요. 제가 쓰는 30일 체크리스트가 필요하면 댓글에 '자료'라고 남겨 주세요 📩

### 세트 B — "자동화 프로그램, 받기 전에 확인할 것"

| 장 | 문구 |
|---|---|
| 1 | "무료 자동화 프로그램" 받기 전에 꼭 보세요 |
| 2 | ❶ 아이디·비밀번호를 넣으라고 한다 → 위험 |
| 3 | ❷ 자동 좋아요·팔로우·댓글 기능 → 약관 위반 가능 |
| 4 | ❸ 출처를 알 수 없는 실행 파일 → 개인정보 유출 위험 |
| 5 | 안전한 방법: 메타 공식 API + 내 토큰 |
| 6 | 공식 API로 자동 발행하는 법, 전자책에 정리했어요 |

**캡션:** 계정은 한 번 잃으면 되찾기 어려워요. 공식적으로 열려 있는 길로 가요. (전자책 링크는 프로필에)

### 세트 C — "첫 줄 공식 12가지"

| 장 | 문구 |
|---|---|
| 1 | 스크롤을 멈추게 하는 첫 줄 공식 12 |
| 2 | 숫자+결과 / 실패 고백 / 금지 |
| 3 | 비밀 공개 / 비교 / 질문 |
| 4 | 대상 호명 / 시간 / 반전 |
| 5 | 구체적 금액(실제 숫자만!) / 도구 공개 / 저장 유도 |

### ManyChat 설정 (댓글 키워드 → DM 자동 발송)

1. ManyChat 가입 → 인스타그램 비즈니스·크리에이터 계정 연결
2. Automation → **"Comment on your post or reel"** 템플릿 선택
3. 키워드: `자료`, `신청` / 대상 게시물: 해당 카드뉴스
4. 공개 답글: "DM 보냈어요! 📩" (2~3개 문구를 돌려 쓰기)
5. DM: "신청 감사해요! 체크리스트는 여기 있어요 👉 [신청 폼 링크]"
6. 신청 폼에서 이메일과 **개인정보 수집·광고 수신 동의**를 받기

## 2. 크몽 상세페이지

### 제목 (30자 안팎)
- 계정 안 날리는 스레드 자동화 · 공식 API 자동발행 도구 포함
- (대안) AI 스레드 30일 자동발행 시스템 · 전자책+도구

### 한 줄 소개
AI로 30일 치 글을 쓰고, 공식 API로 매일 자동 발행하고, 답글을 매출로 바꾸는 과정을 도구와 함께 드립니다.

### 이런 분께 필요해요
- 스레드를 시작했는데 2주를 못 넘기는 분
- "자동화 프로그램"을 받았다가 계정이 제한될까 불안한 분
- 조회수는 나오는데 수익으로 이어지지 않는 분
- 본업(가게·회사·프리랜서)을 SNS로 알리고 싶은데 시간이 없는 분
- 내 노하우로 전자책을 만들어 팔고 싶은 분

### 읽고 나면 할 수 있어요
1. 내 계정의 방향을 한 줄로 정하고, AI로 30일 치 원고 90개를 만들 수 있어요
2. 메타 공식 Threads API로 컴퓨터를 꺼 둬도 글이 올라가게 만들 수 있어요
3. "댓글에 '자료'" → 자동 답글 → 무료 자료 → 유료 상품으로 이어지는 퍼널을 만들 수 있어요
4. 조회수·답글률을 보고 다음 주 글을 고칠 수 있어요
5. 스레드 글을 인스타그램 카드뉴스와 자동 DM으로 넓힐 수 있어요

### 저자 소개 (실제 경험만)

### 자주 묻는 질문
- **코딩을 몰라도 되나요?** 명령어 4개로 실행할 수 있습니다. 코딩 없는 방법(공식 예약 기능, 노코드 도구)도 함께 안내합니다.
- **수익이 보장되나요?** 아니요. 이 책은 매일 글이 올라가고 그 글이 상품으로 이어지는 시스템을 만드는 방법을 알려 드립니다. 수익은 운영과 상품에 따라 다릅니다.
- **계정 정지 위험은 없나요?** 메타 공식 API만 씁니다. 로그인 정보를 넣는 매크로나 자동 좋아요·팔로우는 쓰지 않습니다. 그래도 스팸성 운영을 하면 제한될 수 있으므로 책의 10가지 규칙을 지켜 주세요.
- **윈도우에서도 되나요?** 네. Node.js만 설치하면 윈도우와 맥 모두 됩니다.
- **업데이트는요?** API가 바뀌면 개정판을 구매자에게 무료로 드립니다.

### 환불·저작권 안내
- 파일을 받은 뒤에는 디지털 콘텐츠 특성상 청약 철회가 제한될 수 있으며, 판매 플랫폼의 환불 규정을 따릅니다.
- 구매자 1인 사용 목적입니다. 무단 복제·배포·재판매를 금지합니다.

### 상세페이지 이미지 구성 (5장)
1. 표지 + 한 줄 약속: "잠든 사이에도 글이 올라간다"
2. 문제: 지침 · 수익 없음 · 계정 정지 불안 (아이콘 3개)
3. 해결 구조: AI 원고 → 자동 발행 → 답글 → 무료 자료 → 상품 (흐름도)
4. 구성품: 전자책 + 도구 + 프롬프트 + 30일 플랜
5. 실제 화면: 자동 발행 기록 캡처, `insights` 결과 표 (실제 데이터)
