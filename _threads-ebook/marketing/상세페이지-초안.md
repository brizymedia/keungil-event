## A. 소그룹 기수 상세페이지 (1기 · 149,000원)

### ① 오프닝 — 실제 기록만
> (1기) 베타 10명 모집, [ ]시간 만에 마감
> (2기 이후) 1기 20명 [ ]분 만에 마감 · 대기자 [ ]명

베타 참여자 후기 캡처 1~2개 (동의받은 것)

### ② 훅 + 자격
**AI로 스레드 자동화, 하고 싶으시죠?**
방법만 알려 주는 강의는 많습니다.
**저희는 돌아가는 도구까지 드립니다.**

전남에서 행사 회사를 운영하며
회사 블로그·갤러리를 [ ]개월째 자동으로 발행하고 있습니다.
같은 방식으로 스레드 계정 2개를 운영하고 있습니다.

### ③ 초반 후기 + 가격 계단
| 1기 (지금) | 2기 | 3기 |
|---|---|---|
| **149,000원** | 190,000원 | 250,000원 |
기수마다 도구와 강의가 업데이트되고, 가격도 한 단계씩 오릅니다. **공지한 가격은 그대로 지킵니다.**

### ④ 문제 → 전후 비교
**스레드, 왜 매일 밀릴까요?**
주제 고민 → 글쓰기 → 답글 확인 → 시간 맞춰 올리기. 한 달이면 90번입니다.
▼
**AI + 공식 API로 준비하면 → 일주일에 30분**
일요일 30분 편집 → 21개 예약 → 평일엔 답글만.

### ⑤ 증거 (실제 숫자만)
- 두 계정 30일 기록: 발행 [ ]개 · 누락 0건 · 월 조회수 [ ] · 답글률 [ ]%
- `insights` 결과 표 캡처, GitHub Actions 발행 기록 캡처
- 무료 자료 신청 [ ]명

### ⑥ 참여자 결과 (수익 배수 말고 과정 성과)
- "[ ]주 만에 첫 자동 발행 성공" · "주 [ ]시간 아꼈어요" · "처음으로 한 달 동안 빠짐없이 올렸어요"

### ⑦ 반론 처리 — 계정 걱정
**"자동화하면 계정 정지되지 않나요?"**
- 메타가 공식으로 열어 둔 **Threads API**만 씁니다.
- 아이디·비밀번호를 넣는 매크로, 자동 좋아요·팔로우, 남의 게시물 자동 댓글은 **쓰지 않습니다.**
- 자동 답글은 **내 게시물에 달린 답글에만**, 한 사람에 한 번, 간격을 두고 답니다.
- ※ 어떤 방법도 계정 안전을 100% 보장할 수는 없습니다. 그래서 운영 기준 10가지를 함께 드립니다.

### ⑧ 강의력 증명
베타 참여자 후기 3개: "코딩 몰라도 따라 할 수 있었다" 같은 **실제 문장**

### ⑨ 결과물 + 커리큘럼
**4주가 끝나면 내 계정에서 자동 발행이 돌아가고 있습니다.**

| 주차 | 주제 | 끝나면 |
|---|---|---|
| 1주 | 계정 설계 + AI 원고 | 내 계정 한 줄 정의, 원고 90개 |
| 2주 | 공식 API 자동 발행 | 컴퓨터를 꺼 둬도 매일 발행 |
| 3주 | 잘 된 글 분석 → 변형 (`analyze`) | 내 잘 된 글의 패턴 보고서 + 새 원고 |
| 4주 | 답글 → 무료 자료 → 상품 퍼널 | 키워드 자동 답글, 신청 폼, 첫 상품 기획 |

매주 줌 Q&A 1회(녹화 제공) · 1:1 계정 점검 1회 · 단톡방
