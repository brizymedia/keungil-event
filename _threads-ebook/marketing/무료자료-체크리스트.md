# 스레드 첫 30일 체크리스트 (무료 자료)

> 「잠든 사이에도 글이 올라간다」 맛보기 자료 · 자유롭게 공유하셔도 됩니다.

## 1주 차 — 방향 잡기
- [ ] 계정 한 줄 정의: "나는 ___에게 ___을 알려 주는 계정이다."
- [ ] 프로필 이름에 주제 키워드 넣기 (예: "큰길 | AI 자동화 기록")
- [ ] 소개글 3줄: 누구 / 무엇 / 링크로 받을 것
- [ ] 비슷한 주제 계정 10개를 찾아 잘 된 글의 첫 줄만 모으기
- [ ] AI로 첫 주 원고 21개 초안 만들기

## 2주 차 — 꾸준히 올리기
- [ ] 하루 3개 발행 (아침 · 점심 · 저녁)
- [ ] 모든 답글에 24시간 안에 답하기
- [ ] 질문으로 끝나는 글을 하루 1개 넣기
- [ ] 예약 발행 도구 하나 정하기 (공식 기능 / 공식 API)

## 3주 차 — 반응 읽기
- [ ] 조회수 상위 3개 글의 공통점 적기 (틀 · 첫 줄 · 시간대)
- [ ] 반응 없는 유형 1개 줄이기
- [ ] 잘 된 글 1개를 AI로 5개 변형하기
- [ ] 무료 자료 1개 만들기 (체크리스트 · 프롬프트 · 템플릿)

## 4주 차 — 연결하기
- [ ] "댓글에 '자료' 남기면 드려요" 글 주 2회
- [ ] 신청 폼 만들기 (개인정보 수집·광고 수신 동의 포함)
- [ ] 반복해서 받은 질문 3개로 전자책 목차 초안 만들기
- [ ] 30일 회고: 늘릴 것 1개, 줄일 것 1개

## 첫 줄 공식 12가지
숫자+결과 · 실패 고백 · 금지 · 비밀 공개 · 비교 · 질문 · 대상 호명 · 시간 · 반전 · 구체적 금액(실제만) · 도구 공개 · 저장 유도

## 계정 안 날리는 규칙 5가지
1. 로그인 정보를 넘기는 프로그램을 쓰지 않는다
2. 자동 좋아요·팔로우를 하지 않는다
3. 남의 글에 링크 댓글을 자동으로 달지 않는다
4. 같은 문장을 반복해서 올리지 않는다
5. 가짜 후기·가짜 수익 인증을 쓰지 않는다
