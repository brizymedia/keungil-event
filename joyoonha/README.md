# 조윤하 아나운서 — 프로필 페이지 (데모)

CBS 앵커 출신 한·영·일 MC **조윤하 아나운서**의 1페이지 프로필 사이트입니다.
빌드 도구 없이 그냥 열면 동작하는 정적 사이트입니다.

**공개 주소 → https://큰길이벤트.com/joyoonha/**

```
joyoonha/
├─ index.html        # 페이지 내용 (소개 · 진행 분야 · 경력 · 섭외 문의) — 내용은 여기서 바로 고칩니다
├─ css/style.css     # 디자인 (종이색 바탕 × 네이비 잉크, 명조 제목)
├─ js/app.js         # 인터랙션 (등장 애니메이션 · 네비 · 번호 복사 · 공유)
└─ assets/
   ├─ profile.webp   # 프로필 사진 (2026 프로필 A03, 760×1140)
   └─ profile.jpg    # 같은 사진 JPEG (카톡·OG 미리보기용)
```
